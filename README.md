# The Garden of Unfinished Intelligence

Private founding edition · November 24, 2026

Open **site/index.html** directly to enter the Garden. The opening seed lives in publications/book-of-questions/seed-001.md. Edit that source and run `python3 scripts/build.py` to refresh the page. HTML, CSS and system fonts work offline.

| Path | Purpose |
| --- | --- |
| governance/ | Charter, authority and editorial boundaries |
| publications/book-of-questions/ | Canonical text of the first intended publication |
| inquiries/observatory/ | Philosophical and interdisciplinary inquiries |
| research/ | Empirical studies and reproduction notes |
| works/art/ | Original creative works |
| artifacts/glyphs/ | Versions of the evolving glyph and their descriptions |
| provenance/ | Attribution, decisions, disputes, revisions and open questions |
| web/, scripts/, site/ | Website sources, build script and portable reading copy |
| ops/ | Maintenance, restoration and proposed domain configuration |

The technical foundation is a single Git repository. Archive material and private editorial records sit outside the website. The build reads a named seed and template and copies one stylesheet. Keep the public-export list explicit even if the archive grows.

Read governance/charter.md before changing project scope and ops/stewardship.md before transferring or publishing a copy.

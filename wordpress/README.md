# Garden reading edition

The home page is a WordPress Page. The Garden Leaf block theme renders its content. The offline reading copy in site/ uses the same edition. Only named public works enter the build. The glyph shape and its 24 leaves are archived with this edition.

## First publication

Use the authenticated connection to unfinishedintelligence.org. Inspect current user capabilities, active theme, page list, and reading settings. Record the existing front-page settings and active theme before switching. Upload the garden-leaf theme to the Garden, then create a draft page from front-page.blocks.html. Preview, activate Garden Leaf, publish the page and assign it as the static front page. Verify the anonymous HTTPS view and its links on phone and desktop. Keep any pre-existing page available for rollback. Restore the recorded theme and reading settings if required.

## Cultivation

Use a named WordPress identity and revocable connection for each publisher. Routine page editing only requires an account with page publishing rights. The steward manages user roles and theme installation permissions. Keep credentials in the connector. Before updating an existing work, fetch the latest WordPress revision, preserve direct editorial changes in the source, then generate and preview the next edition. Keep contributor, date, status, and sources with each work. Record significant revisions or disputed attribution in provenance/records.json. Keep the previous page revision and theme version available. The build does not export the private ledger or enumerate repository contents.
